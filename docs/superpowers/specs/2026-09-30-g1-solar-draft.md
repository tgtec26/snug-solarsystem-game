## 1. 학습 핵심

**"움직임과 배치가 보이는 모습을 정한다. 실제로 움직이는 것은 지구와 달이고, 지구에서 보면 별과 태양이 돌고 달 모양이 바뀌는 것처럼 보인다."**

- **자전 → 일주 운동**: 지구가 하루에 한 바퀴 서→동으로 도니, 별은 동→서로 도는 것처럼 보인다 (북쪽 하늘은 북극성 중심 시계 반대 방향).
- **공전 → 연주 운동·별자리 변화**: 태양 쪽 별자리는 안 보이고, 태양 반대쪽 별자리는 한밤중 남쪽 하늘에서 잘 보인다.
- **태양·지구·달의 배치 → 위상·식**: 달이 태양과 같은 방향이면 삭, 반대 방향이면 망. 태양-달-지구 일직선이면 일식(삭), 태양-지구-달 일직선이면 월식(망).
- **특징이 천체를 정한다**: 스스로 빛을 내면 태양. 질량·반지름·표면·고리·위성 수로 지구형·목성형 행성을 가른다. 태양 활동이 세지면 흑점·홍염·플레어·코로나·태양풍이 함께 커지고 지구에 영향이 온다.
- 게임 원칙 "선택 = 결과, 조작 결과 = 특징"은 **"어디에 놓느냐(배치) = 무엇이 보이느냐(결과), 망원경·모형 조작 = 관측 일지에 남는 특징"** 으로 이어진다.

## 2. 과학적 정확성 (반드시 유지)

교과서 용어·정의를 그대로 쓴다. 상세는 발췌 문서 2장. 읽기가 불확실한 값은 **확인 필요 C1~C9**(발췌 2-12)로 두고 JSON에 `verified:false`로 표시, 게임 판정에 쓰지 않는다.

| 개념 | 게임에서 지킬 것 |
|---|---|
| 태양계 구성 천체 | 태양(유일하게 스스로 빛, 주로 수소·헬륨) · 행성(태양 주위 공전, 크기 크고 중력 큰 8개) · 왜소 행성(둥글지만 질량·크기 작음, 명왕성·세레스) · 소행성(주로 화성·목성 궤도 사이, 모양 불규칙) · 혜성(얼음과 먼지, 타원 궤도, 꼬리는 태양 **반대쪽**) · 위성(행성 주위 공전, 달은 지구의 위성) |
| 행성 8개 | 수성·금성·지구·화성·목성·토성·천왕성·해왕성 (본문 나열 순서). 특징은 230~231쪽 문장만. "주로 수소와 헬륨"은 태양·목성·토성에만. 이오가 어느 행성의 위성인지 쓰지 않음 |
| 행성 분류 | 지구형(수·금·지·화): 질량·반지름 작다, 표면 단단한 암석, 고리 없다, 위성 없거나 적다. 목성형(목·토·천·해): 질량·반지름 크다, 표면 기체, 고리 있다, 위성 많다. **정성 값만** (그래프 수치 C1·C2 미사용) |
| 태양 표면·대기 | 광구(쌀알 무늬=대류 현상, 흑점=주변보다 온도 낮음, 수는 약 11년 주기). 대기: 채층(붉은색 얇은 층)·코로나(백색, 멀리 뻗음). 대기는 평소 안 보이고 **달이 광구를 완전히 가릴 때** 관찰. 홍염(불꽃처럼 코로나까지)·플레어(흑점 부근 폭발) |
| 태양 활동·영향 | 태양풍 = 태양에서 방출되는 입자의 흐름. 활발하면 흑점↑·홍염·플레어 잦음·코로나 커짐·태양풍 강해짐. 영향: 오로라(고위도에서 더 넓게·자주), 무선 통신, 인공위성, 정전, 태양 방사선(북극 지방 비행·우주인) |
| 일주 운동 | 지구 자전(서→동, 하루 한 바퀴) 때문에 천체가 하루 한 바퀴 도는 **겉보기 운동**. 방향은 자전과 반대(동→서). 동쪽에서 비스듬히 떠 남쪽을 지나 서쪽으로 비스듬히 짐. 북쪽 하늘은 북극성 중심 시계 반대 방향. 천구 = 가상의 둥근 하늘. 회전각 수치는 화면에 쓰지 않음 |
| 연주 운동·별자리 | 지구 공전(서→동, 1년). 태양이 별자리 사이를 서→동으로 이동하는 겉보기 운동(방향은 공전과 같음). 황도·황도 12궁. 태양 쪽 별자리는 관측 어려움, 반대쪽은 한밤중 남쪽 하늘에서 잘 관측. 확정 사례: 8월 염소자리(반대쪽)·게자리(태양 쪽), 물고기자리는 가을철. 월별 배열은 C4 |
| 달의 위상 | 달은 스스로 빛을 못 내고 태양 빛을 받은 부분만 반사. 약 한 달에 한 바퀴 공전. 삭(태양과 같은 방향)·초승달(삭~상현 사이)·상현(직각, 오른쪽 반원)·망=보름달(반대 방향)·하현(직각, 왼쪽 반원)·그믐달(하현~삭 사이). **상현~망, 망~하현 사이는 이름을 주지 않는다** |
| 일식·월식 | 일식: 태양이 달에 가려짐, **태양-달-지구** 순, 달의 위상 **삭**. 월식: 달이 지구 그림자 속으로, **태양-지구-달** 순, 위상 **망**. 개기(전체)·부분(일부). 개기월식은 붉게 보임(지구 대기에서 굴절된 빛 일부) |
| 수치 | 교과서에 있는 것만: 행성 8개, 흑점 약 11년, 자전 하루, 공전 1년, 달 공전 약 한 달, 황도 12궁, 별자리판 90° 간격, 다누리 사실(발사 2022.8.5 등). 행성 크기·거리·주기 수치는 쓰지 않음 |
| 안전 | 망원경으로 태양을 직접 보지 않는다(차단판·투영판). 손전등 빛을 눈에 직접 비추지 않는다. 조작 규칙으로 구현 |
| 용어 | 소행성대·암석형·가스형·금환일식·본영·반영·남중·고도·상현망간·달의 자전·계절 변화 원인 X. 별과 우주(2학년 Ⅷ) 내용(별의 밝기·색·거리, 은하, 핵융합 등) X |

- 위성은 "행성 주위를 공전하는 천체"로만 묻는다. "위성은 태양 주위를 공전하는가"는 묻지 않는다 (C6).
- 달 위치 8개 중 이름이 없는 2곳은 이름표를 주지 않고 "모양만 기록"으로 처리한다.

## 3. 게임 한 줄 요약

주인공은 동네 **별빛 천문대의 견습 관측자**(견습생 재사용 여부는 결정 3). 천문대지기가 **관측 의뢰**를 내면, **망원경을 조준**해 달과 행성을 찍고, 천체 **특징 카드를 알맞은 자리에 놓아** 태양계 식구와 행성 두 집단을 가르고, 태양 투영판에서 **쌀알 무늬와 흑점**을 찾고, **활동 세기를 올려** 지구 영향을 예보한다. 밤에는 **시간을 돌려** 별이 도는 모습을 보고, **지구를 궤도에서 옮겨** 계절 별자리를 찾고, **달을 궤도 위에 놓아** 위상을 만들고, 마지막엔 **그림자 모형**에서 일직선 순서로 일식과 월식을 만든다. 모은 사진과 카드는 **관측 일지**에 붙고, 개기일식 때만 태양의 대기(채층·코로나)가 열린다.

## 4. 구조 (천문대 지도 + 의뢰서, `ObservatoryScene`)

이 단원의 과학 구조는 **"운동·배치 → 보이는 모습"** 이다. 교과서도 자전·공전을 "우주에서 바라보는 관점"으로 설명하라고 한다(244, 246쪽). 그래서 중단원 2의 방에는 **이중 시점 화면**(우주에서 본 모습 ⇄ 지구에서 본 모습)을 둔다. 중단원 1은 **특징 → 이름표(분류)** 와 **원인 → 영향**이다.

```
[의뢰판: 천문대지기]
   의뢰 0 튜토리얼 "오늘 밤의 손님"     : 망원경 조준 (달·행성)
   의뢰 1 "태양계 식구 맞히기"          : 식구 카드 → 행성 나눔판
   의뢰 2 "태양에 검은 점이 있다"       : 태양 투영판 → 활동 예보
   의뢰 3 "북쪽 하늘의 회전목마"        : 하루 동안 별
   의뢰 4 "생일 무렵의 별자리"          : 별자리 회전의자
   의뢰 5 "달이 모양을 바꾼 날"         : 달 위상판
   의뢰 6 "그림자가 진 날"              : 그림자 모형 → 엔딩(다누리)

[방] 자료실 ─▶ 행성 분류대 ─▶ 태양 관측대 ─▶ 야간 관측 돔 ─▶ 모형 공작실
     (천체 특징)  (두 집단)    (광구·대기·활동)  (일주·연주 운동)  (위상·식)

[이중 시점 — 야간 관측 돔, 모형 공작실]
  ┌ 우주에서 본 모습 ┐   토글(탭 / Tab)   ┌ 지구에서 본 모습 ┐
  │ 지구·달·태양 배치 │  ◀───────────────▶ │ 별·태양·달 모양   │
  └──────────────────┘                    └──────────────────┘
```

- **의뢰 하나 = 천문 현상 하나.** 의뢰서에는 "오늘 밤 북쪽 하늘", "8월 한밤중" 같은 **관측 조건**만 적혀 있고, 결과는 방에서 놓은 위치로 정해진다.
- **갈림길**은 세 곳: ① 행성 나눔판에서 "어느 기준(질량·반지름·표면·고리·위성 수)으로 가를까" ② 별자리 회전의자에서 "태양 쪽 / 한밤중 남쪽 하늘" ③ 그림자 모형에서 "달을 태양과 지구 사이에 놓을까, 지구 뒤에 놓을까".
- 잘못 놓으면 교과서 문장으로 막힌다: 차단판 없이 태양 조준 → "태양을 직접 보지 않아요", 혜성 꼬리를 태양 쪽에 그림 → "혜성의 꼬리는 태양 반대쪽", 달을 태양 쪽에 놓고 보름달이라 답함 → "태양과 같은 방향이면 삭 — 달이 안 보여요".
- **개기일식 해금**: 태양 관측대의 채층·코로나 카드는 평소 잠겨 있고, 의뢰 6에서 개기일식을 만들면 열린다 (237쪽 "달이 광구를 완전히 가릴 때").

## 5. 미니게임 (방별, 교과서 탐구·활동과 1:1 대응)

조작: 터치(드래그·탭·길게 누르기), 키보드 대체(Tab 대상 이동, 방향키 이동·슬라이더, Enter 놓기·확인, Space 누르고 있기 = 길게 누르기). 크롬북 1280×800.

|---|---|---|---|

## 6. 진행·보상

- **관측 일지 4절, 카드 37장**: 천체 14(식구 6 + 행성 8), 태양 7(광구·쌀알 무늬·흑점·채층·코로나·홍염·플레어), 밤하늘 6(일주 운동·연주 운동·별자리 4종), 달과 그림자 10(위상 6 + 식 4). 자료실 카드(파커 탐사선·다누리·항공 우주 공학 기술자·천문대)는 의뢰 완료 보상.
- **한 판 = 튜토리얼 + 의뢰 6개, 12분 내외 (최대 15분).** 미니게임 9개를 모두 거침(약 9분) + 퀴즈 6문항 + 엔딩.
- 별점: 조작 정확도(조준 오차·배치) + 첫 시도 + 의뢰 후 퀴즈 1문항(발췌 3장 26행).
- 엔딩: 관측 일지 한 권 완성, 다누리 지구–달 공전 사진 넘기기, 도감 진행률.

## 7. 기술 (암석 순환·물질 분리 공방·입자 공작소 구조 재사용)

- Next.js 16 + Phaser 4 + zustand, Phaser 캔버스 + React 오버레이. 상태 전이는 기존 store 액션 규칙을 따른다.
- `game/rules.ts` 순수 함수(제안): `matchTrait(bodyId, traitId)`, `classifyPlanet(traits[])`, `planetGroup(planetId)`, `sunActivity(level)`, `earthEffects(level)`, `atmosphereVisible(eclipse)`, `apparentMotion(direction, hour)`, `skyAtPosition(index)`, `moonPhase(angleFromSun)`(이름 없는 구간은 `null`), `litSide(angleFromSun)`, `eclipseOf(order, overlap)`, `orderDone(orderId, state)`, `starsFor(accuracy, attempts, quiz)`.
- 데이터 `public/data/*.json`: `bodies.json`(천체 6·행성 8·분류 기준), `sun.json`, `sky.json`(일주·연주 운동, 별자리판 4, 황도 12궁 이름, `verified` 플래그), `moon-eclipse.json`(위상 6, 위치 8, 식 4), `orders.json`(의뢰·관측 조건·대사), `quiz-pool.json`(발췌 3장 26행), `minigame-config.json`. `/admin` 탭 7개.
- 테스트: 특징 → 천체 대응, 5기준 → 지구형/목성형, 활동 세기 → 네 가지 동시 변화, 개기일식만 대기 해금, 일주 운동 방향, 공전 위치 → 태양 쪽·반대쪽 별자리, 각도 → 위상 이름(이름 없는 구간 null), 일직선 순서 → 일식/월식과 삭/망, JSON 검증(`verified:false`는 판정 제외).
- 그림: 천문대 배경 1, 방 배경 5, NPC(천문대지기) 1, 주인공, 천체 아이콘 14(태양·행성 8·왜소 행성·소행성·혜성·위성), 장치(천체 망원경, 태양 투영판, 별자리판·회전의자, 달 위상판, 손전등·공 받침판) — SVG 우선. 수치 라벨 없이 그린다.

## 9. 결정 필요

1. **두 중단원을 한 게임으로 묶을까, 둘로 나눌까** — (A) **한 게임 "별빛 천문대"** ★추천: 한 판 12분으로 기준(10~15분)에 맞고, 방 5개가 "특징 → 배치 → 겉보기 현상" 순으로 이어지며, 개기일식이 태양 대기를 여는 연결(237 ↔ 253쪽)이 산다. (B) 둘로 분리(태양계 도감 / 지구와 달 모형): 한 판이 6분 안팎으로 짧아지고 저장소·admin이 둘이 된다.
2. **세계관** — (A) **동네 천문대 관측 일지** ★추천: 교과서가 천문대(240쪽)·망원경·관측 일지(232쪽)를 직접 쓰고 기존 기획(암석 순환·물질 분리 공방·입자 공작소)과 겹치지 않는다. (B) 달 탐사 관제센터(다누리·항공 우주 공학 기술자): 교과서 비중이 251, 254쪽 각 1쪽뿐이라 전 범위를 담기 어렵다.
3. **주인공 '견습생' 재사용** — (A) **재사용 + 관측복 스킨** ★추천: 자산 공유, 학습자 연속성. 이미 공작소에서 재사용한 선례. (B) 새 캐릭터 "견습 관측자": 그림 작업이 늘어난다.
4. **한 판 구성** — (A) **튜토리얼 + 의뢰 6개 고정, 12분** ★추천: 9개 탐구를 빠짐없이 거친다. (B) 의뢰 풀에서 4개를 골라 8분: 여러 판 반복이 필요하고 일부 탐구를 놓친다.
5. **확인 필요(C1~C9) 처리** — (A) **v1은 확인 필요 값을 판정에서 제외** ★추천: 행성은 정성 값, 별자리는 별자리판 4종 + 8월 사례, 위상은 각도로 판정. (B) 원본 그림을 사람이 확인해 12궁 월별 배열·위치 1~8 대응·그래프 수치를 채운 뒤 v2에서 확장.
6. **저장소 이름·포트** — **제안값 그대로** ★추천: `snug-solar-system-game`, dev 포트 3500 (혈액 3000, 암석 3100, 전기 3200, 물질의 특성 3300, 물질의 구성 3400). 구현 순서는 전기와 자기·물질의 특성·물질의 구성 다음으로 미정.
