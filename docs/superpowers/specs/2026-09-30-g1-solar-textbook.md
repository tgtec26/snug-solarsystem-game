## 2. 과학적 정확성 (반드시 유지 — 교과서 표현 그대로)

### 2-1. 태양계와 구성 천체 (228~231쪽)
- **태양계**: 태양과 태양 주위를 공전하는 천체 및 이들이 차지하는 공간. 태양, 행성, 왜소 행성, 소행성, 혜성, 위성 등으로 이루어짐 (228쪽).
- 구성 천체 여섯 가지 (230~231, 241쪽 요약).

| 천체 | 교과서 특징 | 예 |
|---|---|---|
| 태양 | 태양계에서 **유일하게 스스로 빛을 내는** 천체. 태양계의 중심. 주로 수소와 헬륨 | |
| 행성 | 태양 주위를 공전하며 **크기가 크고 중력이 큰 8개**의 천체(241쪽). 크기·표면 특징이 다양, 위성·고리를 가진 것도 있음 | 수성~해왕성 8개 |
| 왜소 행성 | 태양 주위를 공전하는 천체 중 **모양이 둥글지만 행성에 비해 질량과 크기가 작은** 천체 | 명왕성, 세레스 (229쪽) |
| 소행성 | **주로 화성과 목성의 공전 궤도 사이**에서 태양 주위를 공전. 모양이 불규칙, 크기 다양 | |
| 혜성 | **얼음과 먼지**로 이루어지고 대부분 태양 주위를 **타원 궤도**로 공전. 태양에 가까워지면 **태양 반대쪽**으로 꼬리 | |
| 위성 | **행성 주위**를 공전하는 천체 | 달(지구의 위성, 230쪽), 이오(229쪽 예시) |

- 모두 스스로 빛을 내는 것은 아님 → 스스로 빛을 내는 것은 태양뿐 (233쪽 확인 1 ×).
- 229쪽 카드 특징 줄이 섞여 태양·왜소 행성의 특징 배정이 불확실 → **C7**. 게임은 230~231쪽 정의만 쓴다.
- 이오가 어느 행성의 위성인지 본문에 없음 → 게임에서 "목성의 위성"이라 쓰지 않는다.

### 2-2. 태양계 행성 8개 (230~231쪽)
행성: **수성, 금성, 지구, 화성, 목성, 토성, 천왕성, 해왕성** (본문 나열 순서). 258쪽 문제 2가 "태양으로부터 가까운 순" 나열을 요구하며 이 순서와 일치. 거리 수치는 교과서에 없음.

| 행성 | 교과서 특징 (요약) |
|---|---|
| 수성 | 대기가 거의 없어 낮과 밤의 온도 차가 매우 크고, 표면에 **운석 구덩이**가 많다 |
| 금성 | **이산화 탄소**로 이루어진 두꺼운 대기 → 표면 온도가 매우 높다 |
| 지구 | 행성 중 **유일하게** 표면에 액체 상태의 물과 생명체가 존재 |
| 화성 | 표면이 붉게 보임, 과거에 물이 흐른 흔적, 극지방에 얼음과 드라이아이스로 된 흰색 **극관** |
| 목성 | 주로 수소와 헬륨. 적도와 나란한 줄무늬, 대기 소용돌이 **대적점**. 희미한 고리, 위성 많음 |
| 토성 | 주로 수소와 헬륨. 적도와 나란한 줄무늬. **뚜렷한 고리**, 위성 많음 |
| 천왕성 | 청록색으로 보임. **자전축이 공전 궤도면과 거의 나란**. 희미한 고리와 위성들 |
| 해왕성 | 청록색으로 보임. 대기 소용돌이 **대흑점**. 희미한 고리와 위성들 |

- "주로 수소와 헬륨"은 태양·목성·토성에만 적혀 있음. 천왕성·해왕성 성분은 본문에 없음.

### 2-3. 행성 분류 (234~235, 241쪽)
- 행성은 특징에 따라 **지구형 행성**과 **목성형 행성**으로 분류.

| 구분 | 지구형 행성 | 목성형 행성 |
|---|---|---|
| 행성 | 수성, 금성, 지구, 화성 | 목성, 토성, 천왕성, 해왕성 |
| 질량 | 작다 | 크다 |
| 반지름 | 작다 | 크다 |
| 표면 | 단단한 암석 | 기체 |
| 고리 | 없다 | 있다 |
| 위성 수 | 없거나 적다 | 많다 |

- 분류 기준 5가지(질량·반지름·표면·고리·위성 수)는 모두 "작다/크다, 암석/기체, 없다/있다" 식 **정성 표현**.
- 234쪽 탐구 그래프의 축·눈금·행성별 값은 읽을 수 없음 → **C1**. 235쪽 확인 2, 241쪽 (가)(나)의 집단 배정 → **C2**.
- 행성 분류는 초등학교 '밤하늘 관찰' 단원과 연계(235쪽 보조단).

### 2-4. 태양의 표면과 대기 (236~237쪽)
| 구분 | 용어 | 교과서 설명 |
|---|---|---|
| 표면 | **광구** | 우리 눈에 보이는 태양의 둥근 표면 |
| 표면 | **쌀알 무늬** | 광구에 쌀알을 뿌려 놓은 듯한 무늬. 광구 아래의 **대류 현상** 때문에 생성 |
| 표면 | **흑점** | 광구의 어두운 무늬. **주변보다 온도가 낮아** 어둡게 보임. 수명·크기·모양 다양. 수는 **약 11년 주기**로 변함 |
| 대기 | **채층** | 광구 바로 위 **붉은색**의 얇은 대기층 |
| 대기 | **코로나** | 채층 위로 멀리 뻗은 **백색**의 대기층 |
| 대기 | **홍염** | 광구나 채층의 물질이 불꽃처럼 코로나까지 뻗어 나가는 현상. 고리 모양도 있음 |
| 대기 | **플레어** | **흑점 부근**에서 일어나는 강력한 폭발. 많은 물질과 에너지가 우주 공간으로 방출 |

- 태양의 대기는 광구보다 어두워 평소에는 볼 수 없고, **달이 태양의 광구를 완전히 가릴 때** 관찰할 수 있음 (237쪽). → 개기일식(253쪽)과 연결.
- 관측 안전(236쪽): 천체 망원경으로 태양을 **직접 보지 않는다**, 파인더 뚜껑은 닫아 둔다, 관측 후 경통 뚜껑을 닫고 식힌다. 촬영 시에는 태양 관측 안경 사용(257쪽).
- 고려 시대 기록에 "태양에 검은 점이 있다"(236쪽 도입).

### 2-5. 태양의 활동과 지구 영향 (238~239쪽)
- **태양풍**: 태양에서 방출되는 **입자의 흐름**. 태양은 끊임없이 물질과 에너지를 방출.
- **태양의 활동이 활발한 시기**: 흑점 수 많아짐 · 홍염과 플레어 자주 발생 · 코로나 크기 커짐 · 태양풍 더 강해짐.
- **지구에 미치는 영향**: 오로라가 자주 발생하고 **발생 지역도 넓어짐**(고위도에서 더 넓게 자주) / 무선 통신 끊김·오류 / 인공위성 고장 / 송전 시설 고장·대규모 정전 / 북극 지방 하늘 비행 승객과 우주인이 **태양 방사선**(태양에서 방출된 고에너지 입자와 빛)에 노출.
- 오로라: 태양풍이 공기 입자와 충돌하며 빛을 냄(238쪽 그림 설명).
- 우리나라는 태양 활동을 실시간 관측·분석해 **예보**하는 시스템 운영(239쪽).
- 기사 예시(238쪽): 흑점 부근 폭발 → 통신 오류 예상 → 항공기가 북극 지방 우회. 기사 속 수치 → **C8**.
- 261쪽 과학 글쓰기: 흑점 수가 주기적으로 변한다는 설명 (2014년 무렵부터 감소, 2020년 이후 증가). 그래프 → **C9**.

### 2-6. 천체 관측 도구 (232~233, 236쪽)
- 천체 망원경: **파인더, 경통, 접안렌즈**. 파인더 중앙에 천체가 오도록 경통 방향 조절 → 접안렌즈로 관측 → 스마트 기기 카메라를 접안렌즈에 가까이 대고 촬영.
- 달은 **상현달일 때** 관측하면 운석 구덩이가 더 입체적으로 보임 (232쪽 도움말).
- 태양 관측: 태양 광선 차단판 + 종이를 고정한 **태양 투영판**, 초점을 맞춰 맺힌 모습을 그림.
- 천문대(240쪽): 대형 천체 망원경으로 어두운 천체도 관측. 관측 시기에 따라 보이는 천체가 달라 날짜별 프로그램 운영. 교과서에 실린 이름: 별마로천문대·중미산천문대·국립과천과학관·소백산천문대·대전시민천문대·보현산천문대·곡성섬진강천문대·김해천문대·제주별빛누리공원 (소재지는 본문에 없음).

### 2-7. 지구의 자전과 일주 운동 (244~245쪽)
- **자전**: 지구가 자전축을 중심으로 **하루에 한 바퀴씩 서쪽에서 동쪽**으로 도는 운동 → 태양이 매일 동쪽에서 떠서 서쪽으로 지는 것처럼 보임.
- **일주 운동**: 별·태양 등이 지구의 자전 때문에 **하루에 한 바퀴씩 원을 그리며 도는 겉보기 운동**. 우주에서 보면 별은 움직이지 않고 지구가 자전.
- **천구**: 별들이 붙어 있는 것처럼 보이는 **가상의 둥근 하늘**. 지구는 천구의 중심.
- 일주 운동 방향은 자전 방향과 **반대**(동 → 서). 별은 **동쪽 하늘에서 비스듬히 떠서 남쪽 하늘을 거쳐 서쪽 하늘에서 비스듬히 지며**, **북쪽 하늘에서는 북극성을 중심으로 시계 반대 방향**으로 회전.
- 3시간 뒤 카시오페이아자리 위치(245쪽 확인 2)는 그림 문항. 본문으로는 "북극성 중심 시계 반대 방향"까지만 확정. 회전 각도 수치는 교과서에 없음.

### 2-8. 지구의 공전과 별자리 변화 (246~247쪽)
- **공전**: 지구가 태양 주위를 **1년에 한 바퀴씩 서쪽에서 동쪽**으로 도는 운동.
- **연주 운동**: 공전하는 지구에서 보면 태양이 **별자리 사이를 서쪽에서 동쪽으로** 이동해 1년 후 처음 위치로 돌아오는 겉보기 운동. 방향은 지구 공전 방향과 같음.
- **황도**: 태양이 연주 운동 하며 지나가는 길. **황도 12궁**: 황도에 있는 12개 별자리.
- 황도 12궁의 이름 12개: 양자리·황소자리·쌍둥이자리·게자리·사자자리·처녀자리·천칭자리·전갈자리·궁수자리·염소자리·물병자리·물고기자리 (247쪽 그림에 모두 등장).
- **태양 쪽 별자리**는 태양 빛 때문에 관측하기 어렵고, **태양 반대쪽 별자리**는 **한밤중에 남쪽 하늘**에서 잘 관측됨 → 지구가 공전하면 계절에 따라 잘 관측되는 별자리가 달라짐.
- 본문이 확정하는 사례: 8월에 염소자리는 태양 반대쪽(한밤중 남쪽 하늘에서 잘 관측), 게자리는 태양 쪽(관측 어려움). 물고기자리는 가을철에 잘 보이고 봄철에는 보기 어렵다 (246쪽).
- 탐구 모형: 전등 = 태양, 관찰자 = 지구. 별자리판 4장은 궁수자리·물고기자리·쌍둥이자리·처녀자리, (가)~(라), 90° 간격. 위치별 답은 **C3**. 월별 배열은 **C4**.

### 2-9. 달의 위상 변화 (248~250쪽)
- **달의 위상**: 지구에서 관측할 때 밝게 보이는 달의 모양. 지구·달·태양의 **상대적 위치**에 따라 달라짐.
- 달은 **스스로 빛을 내지 못하고**, 태양 빛을 받은 부분만 반사하여 밝게 보임. 달이 **약 한 달에 한 바퀴씩 지구 주위를 공전**하므로 밝은 부분이 달라짐. 위상 변화는 약 한 달 주기로 반복 (250쪽 확인 1 ○).

| 위상 | 교과서 설명 |
|---|---|
| **삭** | 지구를 기준으로 달이 **태양과 같은 방향**. 달이 보이지 않음 |
| **초승달** | 삭과 상현 사이. 오른쪽 일부분이 밝음 |
| **상현** (상현달) | 태양·지구·달이 **직각**, **오른쪽 반원**이 밝은 반달 |
| **망** (보름달) | 달이 **태양의 반대 방향**. 달의 앞면 전체가 보이는 보름달 |
| **하현** (하현달) | 태양·지구·달이 **직각**, **왼쪽 반원**이 밝은 반달 |
| **그믐달** | 하현과 삭 사이. 왼쪽 일부분이 밝음 |

- **순서**: 본문은 "삭과 상현 사이 = 초승달", "하현과 삭 사이 = 그믐달"로 서술. 이 관계로 한 주기는 **삭 → 초승달 → 상현 → (망) → 하현 → 그믐달 → 삭**. 망은 삭의 반대 방향. 상현~망, 망~하현 사이 모양에는 교과서가 이름을 주지 않음.
- 추석(음력 8월 15일)에는 보름달이 보임 (250쪽 확인 3).
- 탐구 위치 1~8 ↔ 위상 대응은 그림에서만 읽힘 → **C5**. 정리 1이 묻는 위치는 2·3·5·7·8.
- 달의 공전 방향, 자전, 같은 면만 보이는 이유는 본문에 없음.

### 2-10. 일식과 월식 (252~253쪽)
| 구분 | 교과서 정의 | 배치 (일직선 순서) | 달의 위상 |
|---|---|---|---|
| **일식** | 태양의 전체 또는 일부가 **달에 가려지는** 현상 | **태양, 달, 지구** 순 | **삭** |
| 개기일식 | 태양이 달에 **완전히** 가려짐. 달이 태양 전체를 가리는 지역에서 관측 | | |
| 부분일식 | 태양의 **일부**가 가려짐. 달이 태양 일부를 가리는 지역에서 관측 | | |
| **월식** | 달이 **지구의 그림자 속**으로 들어가 전체 또는 일부가 가려지는 현상 | **태양, 지구, 달** 순 | **망** |
| 개기월식 | 지구 그림자에 달 **전체**가 가려져 **붉게** 보임 | | |
| 부분월식 | 달의 **일부**가 가려짐 | | |

- 개기월식 때 달이 붉게 보이는 까닭(253쪽 참고): 달 전체가 지구 그림자에 들어가도 **지구 대기에서 굴절된 빛의 일부**가 달에서 반사되기 때문.
- 개기일식을 볼 수 있는 지역과 개기월식을 볼 수 있는 지역의 넓이 비교(253쪽 확인 3)는 본문에 답 근거가 없음 → 게임에서 다루지 않음.
- 매달 일식·월식이 일어나지 않는 까닭은 본문에 없음.
- 안전(252쪽): 손전등 빛을 사람 눈에 직접 비추지 않는다, 압정은 면장갑을 끼고 사용. 태양을 볼 때는 태양 관측 안경.

### 2-11. 그 밖의 내용
- **달 탐사선 다누리**(251쪽): 우리나라 최초의 **달 궤도선**. 2022년 8월 5일 발사, 같은 해 12월 28일 달 궤도 진입 성공 → **세계 7번째 달 탐사국**. 2022년 9월 24일, 지구에서 **약 150만 km** 떨어진 곳에서 **10분~20분 간격**으로 달이 지구 주위를 공전하는 모습을 촬영. 임무 제안 예: 달에 도착한 뒤 지구를 촬영해, 달의 공전에 따라 지구 모습이 어떻게 달라지는지 확인.
- **항공 우주 공학 기술자**(254쪽): 우주선·인공위성·비행기 등을 설계하고 개발. 필요한 소양: 전공 지식과 새 분야를 꾸준히 연구하는 노력, 소통과 협업.
- 226쪽: 태양 탐사선 **파커 탐사선**은 매우 빠른 속력으로 태양 가까이 접근에 성공. 태양이 내보내는 물질과 높은 온도 때문에 접근이 어려움.

## 4. 게임화에 쓸 수 있는 조작 단서

1. **망원경 조준** (232~233, 236쪽): 파인더 중앙에 천체 맞추기 → 접안렌즈 → 촬영(달·행성) 또는 태양 투영판에 초점. 교과서가 단계를 이미 제시. 태양은 직접 보지 않는다는 안전 규칙을 조작 규칙으로.
2. **특징 카드 분류** (228~231, 234~235쪽): 스스로 빛을 낸다 / 태양 주위를 공전 / 행성 주위를 공전 카드를 천체 칸에, 행성 8장을 기준 5가지로 두 집단에 놓기.
3. **태양 투영판 스케치** (236~237쪽): 광구의 쌀알 무늬·흑점을 찾아 표시. 채층·코로나는 평소 잠겨 있다가 달이 광구를 가릴 때만 열림.
4. **활동 세기 조절** (238~239쪽): 세기를 올리면 흑점 수·홍염·플레어·코로나·태양풍이 함께 변하고, 지구 쪽 영향(오로라·통신·위성·정전·방사선) 카드가 켜짐.
5. **시간 슬라이더** (244~245쪽): 1시간 간격으로 북·동·남·서 하늘을 바꿔 보며 별의 이동 방향과 회전 중심을 화살표로 기록. 우주 시점(지구 자전)과 지구 시점(겉보기)을 나란히.
6. **공전 위치 드래그** (246~247쪽): 지구(관찰자)를 궤도 위로 옮기면 태양 쪽·반대쪽 별자리와 한밤중 남쪽 하늘의 별자리가 바뀜.
7. **달 위치 드래그** (248~250쪽): 달을 위치 1~8로 옮기면 지구에서 본 밝은 부분이 바뀜. 삭·상현·망·하현은 태양과의 방향(같은 방향·직각·반대 방향)으로 판정.
8. **그림자 모형** (252~253쪽): 손전등(태양) 앞에서 지구·달 공을 일직선으로 옮겨 그림자가 어디에 생기는지 확인. 순서(태양-달-지구 / 태양-지구-달)가 일식·월식을 가름.
