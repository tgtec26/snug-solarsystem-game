## 계획 1 결과 (구현 기록)
- 구조: `shared/src/`(config, validate, journal, inputLock, fullscreen, adminRoute, StageFrame) · `solar-dex/`(Next 16 + React 19 + zustand, Phaser는 계획 2에서 필요할 때 추가).
- `solar-dex/game/rules.ts`: `matchTrait`, `planetGroup`, `criterionValue`, `sunActivity`, `earthEffects`, `cometTail`, `starsFor`, `safetyCheck`, `orderUnlocked`, `allOrdersDone`. 교과서 근거는 주석의 쪽수.
- 데이터: `solar-dex/public/data/` bodies·sun·orders·dialog-config·minigame-config. 로드 시 `validators.ts`로 검증, admin(`/admin`)에서 검증 후 저장(production 403).
- 테스트 29개 통과(`pnpm --filter solar-dex test`), 타입·린트·빌드 통과, 1280×800 기준 흐름 확인(6개 의뢰 완료 → 일지 21장 → 요약).
- 의뢰 방은 `RoomPlaceholder`(개발 모드 "미니게임 완료" 단추)가 대신한다. 계획 2에서 `minigame` id별 오버레이로 교체한다.
- 새 미니게임을 추가하는 방법: ① `rules.ts`에 판정 함수 + 테스트 ② 수치는 `minigame-config.json`(검증기에 규칙 추가) ③ `components/overlays/<Name>Overlay.tsx` ④ `RoomPlaceholder` 대신 `minigame` id로 분기 ⑤ 완료 시 `completeRoom(orderId, stars)`.

## Vercel 연결 (뼈대 푸시 뒤 사용자 작업)
1. Add New → Project → `snug-solarsystem-game` Import → Root Directory `solar-dex`.
2. 게임 B 뼈대가 생기면 같은 저장소를 한 번 더 Import → Root Directory `earth-moon`.
3. "Include source files outside of the Root Directory" 켜짐 확인(`shared/`를 쓰기 때문).

## 계획 2 진행 기록 (2026-10-01)
- 공통 드래그 부품 `shared/src/useDragDrop.ts`: 끌어서 놓기 + 탭-탭(선택 후 자리 탭) + 키보드(Enter). 놓을 자리는 `data-drop="<id>"`.
- 완료한 미니게임(오버레이 `solar-dex/components/overlays/`): `BodiesOverlay`, `PlanetSortOverlay`, `CometOverlay`(꼬리 끝을 끌어 돌림, 방향키·Enter 대체), `ForecastOverlay`(세기 슬라이더 + 영향 카드를 지도 자리에 놓기). `RoomPlaceholder`가 `minigame` id로 분기한다.
- 판정 함수: `pickTraitCards`, `sortPlacement`, `tailAngle`, `tailPointsAway`, `effectZoneOk` (테스트 35개 통과). 수치는 `minigame-config.json`(`bodies.cards`, `comet.tolerance`, `comet.ranks`).
- 브라우저(1280×800 기준)에서 실제 포인터 드래그·키보드로 식구 카드·혜성 꼬리 확인, 행성 나눔판·활동 예보는 키보드 경로로 완주 확인(오답 메시지·별점 포함).
- 알려진 미완: 성공 효과음·음소거(계획 5), 망원경·태양 투영판 미니게임, 결과 PNG, 행성 나눔판과 활동 예보의 실제 포인터 드래그 수동 확인(학교 크롬북 터치로 확인 필요).

## 계획 2 마무리 (2026-10-01)
- `TelescopeOverlay`(파인더 뚜껑 끌어 열기 → 경통 끌어 십자선 중앙 → 초점 다이얼 → 촬영, 달·행성 2장)와 `ProjectionOverlay`(차단판 끼우기 → 상을 종이 가운데로 → 초점 → 흑점 2·쌀알 무늬 찾기). 키보드: 방향키·Enter·Space.
- 판정: `distance`, `focusSharp`, `photoAccuracy`, `telescopeSunCheck`(경로를 따라 확인해 빠르게 끌어도 태양 쪽을 지나지 못함). 수치는 `minigame-config.json`의 `telescope`·`projection`(검증기 포함). 테스트 38개 통과.
- 브라우저 확인(1280×800): 뚜껑·경통 끌기, 태양 차단 메시지, 초점·촬영 플래시, 차단판 순서 안내, 탭-탭 배치, 찾기·결과까지. 차단판의 실제 포인터 끌어놓기는 자동 조작으로는 놓이지 않았고(탭-탭은 동작) 학교 크롬북 터치로 수동 확인이 필요하다. 행성 나눔판·활동 예보와 같은 미확인 항목.
- 알려진 미완: 사진 카드 일지 등록 연출, 효과음(계획 5).

## 계획 3 결과 (게임 B 뼈대, 2026-10-01)
- `earth-moon/`은 `solar-dex/` 뼈대를 복사해 게임 B 데이터로 바꿨다(공통 부품은 `shared/`). 루트 `pnpm-workspace.yaml`·`package.json`(`dev:moon`)에 등록.
- 데이터 `public/data/`: `sky.json`(황도 12궁 월별 배열 247쪽, 별자리판 4장 246쪽), `moon.json`(달 위치 1~8, 4·6은 이름 없음), `orders.json`(의뢰 5개, 카드 28장), `dialog-config.json`, `minigame-config.json`. 모두 `validators.ts`가 교과서 값과 대조해 검증하고 `/admin`에서 저장.
- `rules.ts`: `sunConstellation`, `midnightConstellation`, `zodiacSlotOk`, `chairBoards`, `isEastward`, `moonPositionAngle`, `litFraction`, `phaseName`, `moonLabelOk`, `starsFor`, 의뢰 흐름. 테스트 30개·타입·린트·빌드 통과, 브라우저로 타이틀 → 대사 → 의뢰판 → 방 → 결과 확인.
- 방은 `RoomPlaceholder`(개발용 완료 단추). 계획 4에서 `minigame` id(`earthSpin`, `dayStars`, `constellation`, `moonPhase`, `shadow`)별 오버레이로 교체. `constellation` 의뢰는 회전의자 → 12궁 링 두 단계를 한 오버레이 흐름으로 묶는다.

## 피날레와 완주 QA (2026-10-01)
- 피날레: 마지막 의뢰 결과 → `finale` 단계(`FinaleOverlay`, 약 4.6초: 0.7초 멈춤 → 빛 폭발·팡파르 → 꽃가루 120개·별 카운트업, 입력 잠금 뒤 눌러서 건너뛰기) → 천문대지기 마무리 대사 → 요약 팝업(결과 PNG). store 전이 `result → finale → ending → summary`, 테스트 반영.
- 완주 QA(브라우저, 합성 포인터·키보드·탭 이벤트로 처음~끝): 게임 B 5개 의뢰(별 14개, 일지 28장)·게임 A 6개 의뢰(별 12개, 일지 21장) 모두 완주, 오답 안내·효과 확인. 대사 화면 8연타는 입력 잠금으로 무시, 새로고침 뒤 방에서 이어짐 확인.
- 이 과정에서 발견·수정한 버그: 손을 뗄 때 렌더 이전 상태로 판정하는 문제(그림자 모형·하루 동안 별·별자리·망원경·투영판), 그림자 모형 `grab` 상태가 짧은 끌기에서 늦게 적용되는 문제 → 모두 ref로 최신값 사용.
- 미확인: 실제 터치(크롬북)·손가락 끌기, 실제 소리 청취, 첫 터치 전체 화면, 한 판 소요 시간 실측(10~15분 기준), 시각 점검의 글자 잘림·겹침 전수 확인.

## 망원경 조준 조작 개선 (2026-10-01)
- 사용자 지적: 상을 끄는 조작은 망원경을 돌리는 행동과 다르다. 오른쪽에 망원경을 그리고 **경통 끝(대물렌즈)을 끌어** 상을 찾게 바꿨다(`TelescopeOverlay`). 끝을 끄는 방향의 반대로 하늘이 움직인다(`telescope.tipGain`, 어드민에서 조절). 시야 안을 끌어도 움직이지 않는다. 키보드 방향키 대체는 유지.
- 태양 투영판(`ProjectionOverlay`)은 아직 상을 끄는 방식이다. 같은 방식으로 바꿀지 사용자 결정 대기.
- 지침 U6(이모지·화살표 기호 금지)를 테스트로 고정(`tests/noemoji.test.ts`)하고 소스의 화살표·글자 별(★)을 한글 표현과 `shared/src/Star.tsx`(SVG)로 바꿨다.
