# 그림 작업 목록

플레이스홀더는 SVG 코드로 끝까지 만든 뒤, 가능한 것은 codex 이미지(WebP)로 교체한다. 이모지 금지. `public/assets/`에 넣으면 교체된다(교체 연결은 계획 5).

## 캐릭터 (두 게임 공용, 새로 그린다)
- 관측 대원(가제): 정면 1 + 표정 2 + 망원경 드는 자세 1. 천문대지기 1.
- 프롬프트 기준: 격자 시트 한 장, 중학교 1학년 눈높이, 교과서 일러스트와 어울리는 밝은 화풍, 글자·이모지 없음, 배경 투명.

## 벡터가 꼭 필요한 요소 (사용자가 직접 그리거나 구해서 전달)
- 황도 12궁 별자리 선화 아이콘 12종 (궁수·염소·물병·물고기·양·황소·쌍둥이·게·사자·처녀·천칭·전갈)
- 별자리판 4장 선화 (궁수·물고기·쌍둥이·처녀). 교과서 그림을 그대로 쓰지 말고 별 배치를 참고해 새로 그린다.
- 규격: SVG, 흰 선(투명 배경), 512×512 안.

## 게임 A (태양계 도감)
- 천문대 배경(의뢰판 포함) 1, 방 배경 3(자료실·행성 분류대·태양 관측대), 천체 아이콘 14, 태양 광구 그림(쌀알 무늬·흑점·채층·코로나·홍염·플레어), 장치(천체 망원경, 태양 투영판·차단판).
## 게임 B (지구와 달 모형)
- 방 배경 2(야간 관측 돔·모형 공작실), 장치(별자리판·회전의자, 달 위상판, 손전등·공 받침판).

## 교체 완료 (2026-10-01, codex 생성 → 투명 배경 WebP)
- 공용: `sun.webp`, `telescope.webp` (두 게임 `public/assets/`). 게임 B: `earth-top`(북극 위에서 본 지구, 자전 돌리기), `earth-ball`, `moon-ball`, `flashlight`, `observer`(관측 대원 가안).
- 적용 위치: 혜성 꼬리·지구 자전·별자리·달 위상판·그림자 모형의 태양/지구/달/손전등, 별자리 회전의자 관찰자, 태양 투영판 망원경.
- 남은 교체: 방 배경(천문대·자료실·행성 분류대·태양 관측대·야간 관측 돔·모형 공작실), 천체 아이콘 14, 태양 광구 그림, 차단판, 받침판, 캐릭터 표정·망원경 자세·천문대지기, 벡터 12궁·별자리판(사용자 제작).
- 주의: 생성 이미지는 요청한 납작한 화풍보다 사실적이라 두 스타일이 섞인다. 화풍 통일 여부는 사용자 판단.

## 교체 완료 2차 (2026-10-01)
- 방 배경(codex 생성 WebP, `public/assets/bg/`): 의뢰판 `observatory-wall`(두 게임), 게임 A `library`·`planet-hall`·`sun-deck`, 게임 B `dome`·`workshop`. `UIOverlay`가 의뢰판·방에 따라 깔고 어둡게 덮어 글씨를 살린다. 그림이 없으면 기본 그라데이션.
- 천체 아이콘 14(`solar-dex/public/assets/icons/`): 행성 8(`planet-*`)·식구 6(`body-*`). 격자 시트로 생성해 잘라 화풍을 맞췄다. 식구 카드의 `body-planet`은 지구와 비슷해 보인다(필요하면 다시 요청).
- 남은 교체: 태양 광구 그림(쌀알 무늬·흑점·채층·코로나·홍염·플레어), 차단판·받침판, 캐릭터 표정·망원경 자세·천문대지기, 벡터 12궁·별자리판.

## 교체 완료 3차 (2026-10-01)
- 캐릭터(두 게임 `public/assets/char/`): `keeper`(천문대지기, 대사 화면 왼쪽), `observer-cheer`(결과·요약 화면), `observer-scope`(망원경 조준 화면). 관측 대원의 머리 모양이 `observer.webp`와 조금 다르다(참고 이미지 첨부가 되지 않아 글로 설명해 생성). 필요하면 통일해서 다시 요청.
- 장치: 게임 A `sun-surface`(태양 투영판의 태양 상), `blocker-plate`(차단판), 게임 B `base-plate`(그림자 모형 받침판).
- 황도 12궁 선화 12종(게임 B `public/assets/zodiac/`): codex 생성 PNG를 WebP로 바꾼 **임시본**이다. 지침의 "벡터 직접 제작" 요구는 그대로 남아 있으며, 정식 벡터가 오면 같은 파일명으로 교체한다. 별자리판 4장 선화는 만들지 않았다(판은 가~라 글자로 표시).
- 남은 것: 태양 활동 예보의 코로나·홍염·플레어 전용 그림(지금은 SVG 도형), 천문대지기 표정 변형, 학습 일지(도감) 화면.
- 참고: codex 기본 모델(`~/.codex/config.toml`의 `gpt-6.1-sol`)이 ChatGPT 계정에서 거부되어 `-m gpt-6-astra`를 지정해 생성했다. 참고 이미지 첨부(`-i`)도 같은 오류를 냈다.

## 타이틀 화면 (2026-10-01)
- 첫인상용으로 codex 생성 그림 7종을 `public/assets/title/`에 넣었다: 배경(별빛 하늘·은하수·언덕 위 천문대), 엠블럼(게임 A 태양과 행성 궤도 혼천의, 게임 B 지구·달·태양 궤도), 로고(한글 '별빛 천문대' 타이포그래피), 리본, 단추, 별 반짝임 겹침. 부제(태양계 도감 / 지구와 달 모형)와 '화면을 눌러 시작'은 글자라 코드로 얹는다(게임별 교체 쉬움).
- 로고 한글은 생성 결과가 정확했다. 로고를 바꾸면 글자 오류(획·자모)를 꼭 눈으로 확인할 것.
- 움직임: 엠블럼 떠다님, 로고 빛 맥동, 별 반짝임, 단추 맥동(CSS).

## 식구 카드 화면 개편 (2026-10-01)
- 천체 칸 2행 3열(아이콘 왼쪽 위), 카드 더미(`cards/card-back`)에서 특징 카드(`cards/card-front`)가 한 장씩 나온다. 천체에 붙은 카드는 같은 양피지·금색 테두리.
- 끌기 그림자는 `shared/src/DragGhost.tsx`(포털 + `--stage-scale`)로 커서 한가운데에 놓는다. 무대가 확대·축소돼 있어 `position: fixed`를 무대 안에 두면 어긋나는 버그였다. 행성 나눔판·활동 예보·투영판·12궁 링·달 위상판도 같은 그림자로 교체.

## 행성 나눔판 카드 (2026-10-01)
- 카드: codex 생성 행성 8장(`planetcards/<행성>.webp`, 그 행성의 실제 모습을 배경으로: 수성 크레이터와 태양, 금성 두꺼운 구름, 지구 바다·구름, 화성 붉은 사막, 목성 줄무늬와 대적점, 토성 고리, 천왕성 옅은 청록, 해왕성 짙은 파랑)과 카드 테두리 `frame.webp`(가운데 투명). 이름은 아래 이름판에 글자로.
- 지침 8번(틀린 인상 금지): '수성'의 한자 뜻(물)을 그림으로 옮기지 않고 교과서의 실제 특징(크레이터, 태양에 가까움)을 썼다.
- 끌기 안정화: `useDragDrop`이 창 전체의 pointermove/up을 듣는다(요소에 걸면 카드가 다시 그려질 때 이벤트를 놓쳐 그림자가 커서에서 떨어져 남던 문제). 카드가 가장 많이 겹친 자리를 고르고(`ghost` 크기 지정 시) 끄는 중 놓일 자리를 강조한다(`over`).

## 혜성 꼬리 (2026-10-01)
- 꼬리를 선 대신 codex 생성 그림(`comet-tail.webp`: 얼음 머리 + 푸른 이온 꼬리 + 크림색 먼지 꼬리, 오른쪽으로 갈수록 사라짐)으로 교체. 꼬리 길이는 태양 거리 순위에 따라 그림을 늘려 쓴다. 잡는 손잡이는 반투명 점선 원으로 바꿔 혜성의 일부가 아님을 보인다.
